# Безопасность

Поддерживается текущая alpha-ветка `main`. Для production используй последний commit, прошедший CI и проверенный после публикации.

Об уязвимости сообщи через [закрытый отчёт GitHub](https://github.com/hugo3301/Assistant_BOB/security/advisories/new). Не публикуй ключи, личные сообщения, голосовые, календарные ссылки и чужие задачи в обычных Issues. Для воспроизведения используй вымышленные данные и минимальный пример.

Если ключ раскрыт, отзови его у провайдера. Удаление файла из нового commit не удаляет значение из истории Git. Не присылай действующий ключ сопровождающему в открытый issue.

Внешние AI-провайдеры включаются через отдельное согласие. Серверные endpoints с личными данными требуют аутентификации; Mini App проверяет Telegram initData на сервере. Публичный GigaChat-мост не выполняет генерацию до HMAC и однократного durable claim.

Не отключай TLS-проверку, secret scanning или проверки действий ради обхода ошибки. CI не получает production-ключей приложения; CD получает отдельный ограниченный ключ публикации Cloudflare.
