# Голосовые сообщения BOB

4 ноября 2026, bob-wrh.13. Пришли обычное голосовое Telegram до 2 минут и 2 МБ. BOB скачивает OGG/Opus, распознаёт русскую речь через Cloudflare Workers AI Whisper-large-v3-turbo и передаёт полученный текст прежнему обработчику. В ответе виден блок «Услышал» и фактический результат; создание, перенос и закрытие имеют обычную кнопку возврата. Массовая отмена проходит существующее подтверждение. Голос — вход, ответы пока текстовые. Музыка и произвольные аудиофайлы этим этапом не добавлены.

Реальная длительность проверяется по OGG granule positions/Opus pre-skip, а не только полю duration в update. Проверяются контейнер, границы страниц, дорожка, конец записи, размер после потоковой загрузки и соответствие длительности. Аудиобайты существуют только в памяти обработки и не сохраняются в Git или базе. Расшифровка сохраняется в приватной квитанции конкретного пользователя на 7 дней для восстановления после сбоя; обработанный job очищает исходный payload. Повтор update не распознаёт и не добавляет дело заново. В узком аварийном окне между ответом внешнего API и фиксацией квитанции STT может повториться; бюджет неизвестного исхода списывается консервативно.

Включены русский язык, voice activity detection и отключение продолжения предыдущего текста. Пустой текст, тишина, низкие оценки уверенности, типичные артефакты и чрезмерная расшифровка не исполняются: бот просит перезаписать или написать текстом и сохраняет прежнее уточнение. Для обычной распознанной просьбы нет обязательного второго шага подтверждения. Распознавание может ошибиться в именах/числах; услышанный текст и возврат позволяют исправить результат. Лимит одного сетевого STT-запроса 20 секунд, загрузки Telegram 15; модельный разбор после него имеет прежний ограниченный бюджет времени.

Голос расходует общий и личный лимит из docs/multi-user-budget.md. До запроса резервируется 50 neurons за минуту плюс 1 на запрос; по окончании используется фактический usage.neurons, если он есть. В известных проверках API вернул фактический расход. При отказе/неизвестном исходе списывается резерв. При недоступном распознавании можно воспользоваться текстом; сохранённые напоминания от STT не зависят.

Проверки: 169 Node-тестов, включая длительность и подмену метаданных, тишину, неуверенность, размер/путь файла, общий резерв, повтор STT/действия, отсутствие доступа к чужой расшифровке. Workerd SQLite провёл голосовой update через getFile/download/STT/сохранение/ответ, повтор update не вызвал STT второй раз, счётчик общий между 10 участниками. Внешние API этого интеграционного теста подменены.

Реальные бесплатные вызовы проверены отдельно, только на синтетике, без Telegram и производственных изменений (scripts/check-voice-live.mjs). Локальный русский голос Windows → FFmpeg OGG/Opus, 6.2586 секунды: «Завтра в семь вечера встреча с преподавателем. Напомни за час.» Правильно создана встреча на следующий день в 19:00 Asia/Tomsk, напоминание за 60 минут. STT и запись 2489 мс, API расход 4.864 neurons. Синтетическая тишина 2 секунды: уточнение, ноль созданных дел, 1538 мс, 1.554 neurons. Это не измерение реальной доставки Telegram и не оценка точности на всех голосах/шумах.

Первичные источники: [схема Whisper-large-v3-turbo](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/), [текущая стоимость Workers AI](https://developers.cloudflare.com/workers-ai/platform/pricing/), [Telegram getFile](https://core.telegram.org/bots/api#getfile). Системные Python/FFmpeg не устанавливались: инструмент кодирования для проверки находится только в игнорируемом work/ и не требуется серверу.
