# Автоматический импорт расписания

4 ноября 2026, `bob-wrh.8`.

Пришли BOB файл `.ics` или документ с MIME `text/calendar`, до 1 МБ. Если в нём одна группа занятий, даты, повторения и напоминания добавляются сразу. Подпись «все пары мои» разрешает сразу импортировать весь смешанный календарь.

Если в календаре несколько групп и выбор ещё неизвестен, BOB один раз уточнит свои пары. Можно ответить обычным текстом: «все мои», «только 1 и 3», «первую и третью», «моя подгруппа 2». Номера относятся к списку в ответе; подгруппа ищется в названиях и описаниях самого файла. Можно отобрать занятия по названию, например «только Лекция». Команда не обязательна; прежняя `/ical keep 1,3` продолжает работать.

Выбор сохраняется отдельно от номеров строк файла. При следующей загрузке календаря с тем же именем/источником известные выбранные группы импортируются автоматически, исключённые — пропускаются. Новые неизвестные группы не добавляются молча; известные выбранные занятия расставляются, а по новым BOB уточняет полный выбор. Если новый файл содержит только ранее исключённые группы, выбор не сбрасывается.

Повтор той же загрузки/сообщения не создаёт дубликатов. Изменение времени одиночного события с тем же UID обновляет существующую запись и напоминание. Для DAILY/WEEKLY-серий с одним временем в день перенос времени обновляет соответствующие дневные вхождения. EXDATE и явные STATUS:CANCELLED отменяют уже внесённые будущие вхождения; отмена может быть снята обновлённым календарём. Отменённую вручную пару обновление не восстанавливает. При изменении фильтра отменяются только будущие импортированные занятия исключённых групп, личные задачи/встречи не меняются.

Файл обрабатывается как данные. Инструкции в описании занятия не исполняются. Модель для импорта не требуется, импорт и сохранение выбора проходят одной транзакцией. Ограничения: 2500 исходных VEVENT, 20000 шагов расширения повторений, 5000 вхождений на 90 дней. Неподдержанная временная зона, неверная длительность или конфликтующий UID останавливают запись до уточнения. Занятия без точного времени не превращаются в встречи с выдуманным часом.

Группировка использует SUMMARY/DESCRIPTION/LOCATION; если состав этих полей изменился, группа может потребовать нового выбора. Исчезновение записи без явного признака отмены не считается разрешением удалить её: частичный экспорт не должен стереть остальные личные пары. Сложные серии с несколькими временами в день не объединяются по одному только дню. Настоящий файл ТПУ пользователь ещё не предоставил; его особенности нужно проверить отдельно. Пользователь может загрузить его прямо в бота.

Проверка: 17 новых регрессий импорта/фильтров/переносов/отмен, общий набор — 118 тестов. В workerd проверена полная цепочка webhook → getFile → скачивание .ics → автоматический импорт → повторная загрузка с переносом без дубля. SQLite настоящая, внешние API в этом runtime-тесте синтетические. Для разговорной речи отдельно выполнены настоящие вызовы GLM (docs/conversation-input.md). Реальные пользовательские обязанности при проверках не менялись.
