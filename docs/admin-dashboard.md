# Админ-панель и источники метрик

Доступ: `/admin` в личном чате владельца → Telegram Mini App `/dashboard`. Сервер проверяет подпись и срок Telegram initData, затем точное совпадение ID с `TELEGRAM_OWNER_ID`. Клиент не передаёт выбираемый ID владельца, административный ключ не попадает в страницу/URL. Панель только читает; публикация не меняет настройки, дела или согласия провайдеров.

| Раздел | Источник | Достоверность / ограничения |
| --- | --- | --- |
| Регистрации, включённый доступ | Control SQLite `members` | Полные агрегаты реестра, без имён/ID |
| Активность, возврат на следующий день | Агрегаты принятых запросов по UTC-дням | С начала установки телеметрии; возврат D1 только для завершённых когорт |
| Входящие запросы, отказы rate limit | Control при `/admit` | Повтор webhook считается входящим вызовом; выполненные задания отдельно |
| Очереди, напоминания, sync | Обезличенные снимки каждого tenant при drain | Покрытие и возраст снимков видны; нет синхронного обхода всех пользователей при открытии панели |
| Задержки queue / обработка / доставка / LLM / STT / sync / reminders | Измерение wall-clock вокруг компонентов | p50/p95/p99 — верхняя граница корзины гистограммы, не CPU; число измерений показано |
| Токены LLM | Поля usage успешных ответов API | input/output/cache/total раздельно; отсутствующее поле — неизвестно, а не ноль |
| Cloudflare neurons, Groq аудиосекунды, GigaChat tokens | Существующие shared/provider ledgers | Консервативный локальный учёт защитных лимитов BOB, не кабинетный баланс; единицы не складываются |
| Фильтр непрофильного ввода | `response.filtered` после локального маршрутизатора | Число избегнутых модельных обращений, не выдуманная экономия токенов |
| Версия, Cron/alarm, последние ошибки | BUILD_COMMIT и runtime health + агрегаты | Нет обещания исторического uptime до установки сборщика |
| Free CPU / RAM / тарификация / настоящий баланс кабинетов | Сейчас нет источника с нужными правами | Показываются как недоступные; панель не запрашивает новые права и не вызывает платные API |

Хранение: агрегаты по часам и ограниченные гистограммы — 31 день; дедупликационные квитанции телеметрии — 3 дня, активность — 32 дня; аудит чтения/экспорта — 31 день с ограничением 1000 строк. Выбор периода — 24 часа, 7 или 30 дней, экспорт JSON содержит только те же агрегаты. Панель кеширует срез на 15 секунд, общий для владельца лимит 30 чтений/минуту применяется до тяжёлых выборок и сохраняется при перезапуске. Снимки ограничены 1000 последними участниками в одном срезе, степень покрытия показана; глобальные счётчики обращений охватывают всех. Снимки не содержат названий задач, текстов запросов, аудио, адресов календарей и секретов. История до установки телеметрии не восстанавливается из личных сообщений. Пакетная отправка метрик после drain не должна мешать обработке дел; сбой доставки метрик создаёт пробел в наблюдениях, а не повторяет пользовательское действие.

Существующий серверный административный доступ также позволяет GET `/admin/ops?period=day|week|month` с прежним Bearer ADMIN_SECRET. Он предназначен для эксплуатационных проверок; ключ запрещено вставлять в URL или клиент панели. Вход Mini App использует только Telegram initData.

Проверки выполняются на синтетических данных: доступ владельца/чужого аккаунта/истёкшей подписи/другого Origin, отсутствие личных полей, дедупликация, лимиты/ретенция/перезапуск SQLite, гистограммы, вкладки/периоды/экспорт и workerd со stub API. В текущем окружении визуальная проверка браузером недоступна (локальный URL недоступен встроенному браузеру, Windows AX не возвращает окно); скриншотная проверка не заявляется выполненной.
