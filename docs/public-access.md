# Открытая регистрация BOB

6 ноября 2026, bob-wrh.22. Пользователь отменил ограничения альфы: вход теперь через /start в личном чате, без приглашения и общего предела числа участников. ALPHA_ACCESS_MODE=open; прежний закрытый режим остаётся совместимым для тестов/отката конфигурации. Публичная ссылка — https://t.me/mybob_robot. Поделиться ею может любой участник, список участников по-прежнему доступен только владельцу.

Публичная регистрация не даёт доступа к чужим делам или управлению Worker. У каждого Telegram ID прежний отдельный BobObject; существующие дела, настройки и namespace не меняются. Отозванный владельцем участник не может вернуться через /start. Мини-приложение и календари продолжают проверять подпись Telegram/активный статус. Google OAuth пока остаётся Testing, поэтому открытая регистрация BOB сама по себе не снимает ограничения тестовых аккаунтов Google.

Количество зарегистрированных аккаунтов не ограничено приложением. Общий бюджет Cloudflare остаётся 9 000 neurons/сутки, личный верхний предел 800: это общий ограниченный ресурс, а не обещание такого объёма каждому одновременно. Меню, быстрые действия и сохранённые напоминания не требуют модели, но тоже зависят от Free-квот инфраструктуры. Платный переход не включается.

Защита очереди: 30 уникальных входящих обновлений на пользователя в минуту, из них до двух голосовых. Telegram-повторы того же update_id в течение десяти минут не занимают новые места; выполнение и STT также идемпотентны. Частые запросы получают предложение подождать. Входящие лимиты хранятся в ControlObject и сохраняются после перезапуска. Для быстрого синтетического полного прогона отдельный INBOUND_REQUESTS_PER_MINUTE=200; в рабочей конфигурации переопределения нет. Новые участники не получают права отключать лимиты.

Cron выбирает не более 20 наступивших пользователей за запуск через индекс, вместо неограниченного обхода всей базы; собственные alarm участников сохраняются. Неуспешную страховочную побудку повторяет через пять минут, чтобы один сбой не занимал первые места постоянно. Админский обзор возвращает агрегированное количество и первые 50 записей, без загрузки полного списка в память. Полная админ-панель с дашбордами — отдельная задача bob-wrh.25.

Проверки: 298 Node-тестов, в том числе 120 новых аккаунтов в open без приглашений, отзыв доступа, частота/перезапуск/повтор обновления, ограниченные выборки и совместимость закрытого режима. Полный workerd SQLite с прежними календарями/голосом/бюджетами прошёл. Дополнительный check-public-cloud.mjs создал 15 новых синтетических участников через webhook, проверил /start/onboarding и отсутствие чужого дела в другом чате без модельных запросов. Внешние API подменены, реальные Telegram-пользователи не создавались.
