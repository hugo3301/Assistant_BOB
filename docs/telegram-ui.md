# Telegram: понятные списки и карточки

4 ноября 2026, bob-wrh.9. «Сегодня», «Неделя», «Все дела» показывают дела по локальным дням, по шесть на страницу. Время занятия указано интервалом; пересечения отмечены. Технические идентификаторы скрыты. Кнопка номера открывает карточку: завершить задачу, перенести, убрать. Перенос уточняется обычным текстом без модели. «Проекты» показывает количество открытых дел и кнопку каждого проекта. «Настройки» содержит кнопки времени сводки и интервала напоминания. Старые slash-команды сохранены.

Снимок списка и соответствие номеров хранятся 24 часа в SQLite Durable Object, принадлежат конкретному владельцу. Карточка проверяет версию перед изменением; устаревшая показывает актуальное состояние. Повтор Telegram update использует сохранённый результат. Callback проверяется по реальному отправителю и личному чату; ответ на callback снимает индикатор ожидания. Навигация редактирует исходное сообщение. Тексты остаются обычным Unicode, без риска исполнять HTML из календаря.

Проверки: 123 Node-теста, включая прежние 27 экспериментальных проверок политики. Локальный workerd с настоящей SQLite Durable Object: webhook, очередь/outbox, перезапуск, повтор update, скачивание и повторный импорт .ics, callback acknowledgement и editMessageText. Внешние Telegram/AI в интеграционной проверке подменены; реальные пользовательские дела не изменялись. Для проверки интерактивного интерфейса в Telegram нужно заново открыть «Сегодня» или /week: старые сообщения не получают кнопки автоматически.
