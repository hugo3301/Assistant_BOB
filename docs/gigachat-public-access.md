# GigaChat для публичного BOB: результат проверки

16 ноября 2026, bob-wrh.31. Проверены первичные страницы провайдера, текущая конфигурация сервера и защитные тесты. Это продуктово-техническое решение при существующих условиях, а не юридическое заключение и не ответ поддержки.

## Факты и границы вывода

| Источник | Подтверждённое положение | Значение для BOB |
|---|---|---|
| [Соглашение для физлиц](https://developers.sber.ru/docs/ru/policies/gigachat-agreement/individuals), редакция 6 февраля 2026, п. 2.4, 5.3.5 | Бесплатный режим ограничен личным некоммерческим применением; доступы требуется держать конфиденциальными | Скрытый серверный ключ сам по себе не подтверждает право обслуживать им произвольных участников |
| Тот же документ, п. 8.6–8.7, 12.1 | Есть ограничения на загрузку сведений о других людях; для безвозмездного доступа предусмотрена отсылка к отдельному соглашению | Одного согласия участника в /providers недостаточно, чтобы считать разрешённым весь сценарий |
| [Правила бесплатного сервиса](https://developers.sber.ru/docs/ru/policies/gigachat/agreement), редакция 22 июня 2026, п. 1.6, 7.1–7.2 | Партнёрский сценарий описывается через отдельные договорённости; запросы с персональными данными ограничены, включая данные самого пользователя | Нужно выяснить применимый режим именно API-проекта, а не автоматически переносить условия веб-чата на BOB |
| [Коммерческое применение API](https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial), редакция 10 декабря 2025 | Для бесплатного контента заявлено личное применение; коммерческое применение отнесено к платным пакетам | Отсутствие оплаты в BOB не доказывает допустимость общего бесплатного пакета |
| [Тарифы физлиц](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs), редакция 7 октября 2026 | У моделей отдельные пакеты на 12 месяцев и один поток генерации | Большой суммарный объём не является месячным балансом Ultra |

**Вывод:** опубликованные материалы не дают достаточного основания включить общий личный Freemium-ключ для публичного BOB. Это отсутствие подтверждения применимости, а не утверждение, что всякий бесплатный бот запрещён. Персональные данные в обычной речи нельзя гарантированно исключить удалением Telegram ID или регулярным выражением.

## Решение для текущего релиза

Общий доступ GigaChat не включается. Технически остаётся прежний ограниченный режим выбора владельцем; это само по себе не подтверждает допустимость любых персональных данных в его запросах. Остальные участники используют существующий Cloudflare-путь. Новые ключи, получатели данных и платные режимы не подключаются.

Живая read-only проверка `/admin/ops` 16 ноября: `gigachat.public=false`, настроенность для владельца подтверждена, постоянный cap 49 900 000 токенов. Это защитный счётчик BOB, не остаток из кабинета провайдера. Действующие ограничения приложения: один незавершённый резерв, общий суточный предел 500 000, личный суточный предел 20 000/100 запросов; постоянный pool не сбрасывается ежедневно. Дополнительных генераций и отправки пользовательских данных в GigaChat при исследовании не было. Значения secret bindings через Settings API не видны: по их отсутствию в plain_text нельзя делать вывод о runtime-флагах.

## Варианты продолжения

| Вариант | Что нужно до реализации |
|---|---|
| Один бесплатный пакет для участников BOB | Письменное подтверждение провайдера применительно к бесплатному многопользовательскому сервису и содержимому запросов |
| Индивидуальные аккаунты участников | Уточнить возможность делегирования доступа серверу BOB; не собирать личные API-ключи в чате и не выдавать такой вариант за разрешённый автоматически |
| Отдельное обезличивание запросов | Спроектировать и проверить сохранение смысла действий без передачи идентифицирующих данных; это не заменяет разрешения на публичный сервис |
| Договорной/партнёрский доступ | Подтверждённые условия и бюджет владельца; платное подключение сейчас не разрешено |

## Подготовленный запрос провайдеру — не отправлен

Официальная страница [коммерческого применения API](https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial) ссылается на [поддержку API в Telegram](https://t.me/SD_SmartApp_Supprot_Bot). Нужен отдельный явный запрос владельца на отправку обращения; личные данные участников, ключи и примеры настоящих дел в обращение не включать.
