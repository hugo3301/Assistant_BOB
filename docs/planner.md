# Наглядный план BOB

5 ноября 2026, bob-wrh.17. Пользователь выбрал экран внутри Telegram с переключением дат и карточками. Наглядный план дополняет текстовые /today, /week и /ahead; отправка сообщений, голос и напоминания продолжают работать в прежнем чате.

## Выбор представления

| Вариант | На телефоне | Выбор дела и обновление | Бесплатный ресурс |
| --- | --- | --- | --- |
| Текст Telegram | Хорошо читаются последовательные записи; временная сетка и наложения не выражаются | Уже есть кнопки карточек и страницы | Быстрый путь без ИИ, сохранён |
| Изображение | Широкую неделю пришлось бы увеличивать; длинные названия обрезаются | Нельзя нажать отдельную встречу без дополнительного списка; нужна новая картинка после правки | Нужны рендер и доставка медиа, генерация ИИ не нужна |
| Mini App | День в одной колонке; неделя прокручивается вбок, на широком экране помещается целиком | Даты, карточки, фильтры и обновление внутри Telegram | Тот же Worker/DO, HTML/CSS/JS без новых зависимостей и вызовов ИИ; платформенные квоты остаются |

Сравнение и выбор не означают месячный нагрузочный тест. Подключение через inline-кнопку web_app не требует регистрации нового бота или платного сервиса. Main Mini App/BotFather menu в этом этапе не перенастраиваются.

## Поведение

В сообщениях /today, /week, /ahead и общего списка доступна кнопка календаря/обзора. Для «завтра» и явного дня кнопка сохраняет нужную локальную дату. Внутри — «День», «Неделя», «Обзор», выбор даты, стрелки и «Сегодня». Неделя — семь дней от выбранной даты. На мобильном она прокручивается вбок; ось часов и строка дел без времени остаются на экране. Данные загружаются один раз, дальнейшая навигация выполняется локально.

Известная длительность задаёт высоту блока, совпадающие интервалы занимают разные полосы. Очень короткие записи получают минимальную высоту для нажатия: точное время указано в блоке/карточке. В плотной группе остаются две встречи и кнопка «Ещё N дел» с полным списком остальных. Неизвестная длительность и точный срок задачи отмечены пунктиром; это маркер начала/срока, не обещание занятого интервала. Предупреждение о конфликте ставится только по известным абсолютным интервалам. События через полночь делятся по местным дням; многодневные события на весь день видны в каждом дне.

Карточка показывает начало, длительность/конец, смещение времени, источник, проект и напоминание. Изменение/завершение открывает актуальную карточку в BOB через личный deep link, где действуют существующие подтверждения и возврат. Mini App сам не изменяет дела и не отправляет их в календари. При одновременном редактировании бот перечитывает запись.

«Обзор» содержит просроченные задачи, сегодня, ближайшую неделю, дальние планы, дела без даты и ещё открытые прошедшие события отдельной группой. Год явно показан для дальних дат в другом году. Фильтры проектов/сфер и счётчики помогают увидеть общую картину. Проекты без открытых дел сохраняются в выборе и отмечаются как повод проверить следующий шаг. Большой список раскрывается порциями по 80 записей; в ответе сервера нет скрытого горизонта обрезки открытых дел.

Это снимок: видно время загрузки и кнопку обновления. После возвращения в приложение обновление запрашивается, если снимку больше минуты; постоянного опроса нет. Завершённые/отменённые записи не входят в открытый план. Точность сложных дат/сохранённых исходных дел этим интерфейсом не переопределяется. Во время перевода часов сетка остаётся шкалой местных часов; карточки содержат точные смещения, фактические пересечения определяются по UTC.

## Доступ

Публичный GET /planner отдаёт только оболочку. Личные записи выдаются POST /planner/data после проверки HMAC-SHA256 Telegram.WebApp.initData ключом бота, свежести auth_date до 30 минут, отсутствия повторных полей и действующего приглашения. Используется только подписанный user.id; owner из URL/JSON не принимается. Ключи, исходный initData и данные не записываются в URL, localStorage, модель или аналитические сервисы. Общий SDK загружается с официального telegram.org; клиентское initDataUnsafe не используется.

API требует тот же Origin, ограничивает входной размер, отдаёт no-store. Есть CSP, запрет отправки форм и внешних запросов кроме официального SDK, no-referrer; встраивание разрешено доменам Telegram. Чужой/отозванный участник не получает данные. У API лимит 30 обращений в минуту на участника в памяти текущего объекта; это ограничение всплеска, не замена общим квотам Cloudflare. Простое чтение плана не записывает счётчик в SQLite.

POST /planner/item выдаёт короткий deep link только на запись этого владельца. Привязка и срок ссылки проверяются повторно в чате; текущая карточка читается заново. В обычном браузере без подписи показывается инструкция открыть календарь из BOB. Демоданные доступны только в отдельно сгенерированном файле; параметр demo на сервере не включает обход входа.

## Проверки и разработка

Проверены экраны на 390×844, 320×740 и широком размере: день, неделя, карточка, фильтр проекта, пустое состояние и 27 пересекающихся встреч/9 дел без времени. Горизонтального переполнения всей страницы нет; широкая неделя прокручивается в своём контейнере. Сохранены текстовый просмотр, клавиатурные переключения, подписи элементов, видимый фокус и стандартный диалог.

220 Node-тестов прошли. workerd с настоящей SQLite проверяет подписанный вход, изоляцию, отказ постороннему, переход в чат к актуальной карточке, чужую ссылку и браузерную геометрию именно из собранного Worker. Внешние Telegram/AI/календарные API в этом сценарии подменены. Это не подтверждение показа Mini App в конкретной установленной версии Android Telegram; нужен личный пилот кнопки.

Исходники: src/planner/. После изменения calendarGeometry нужно выполнить `node scripts/build-planner-source.mjs`: браузерная копия сохраняется до Wrangler, чтобы не зависеть от его служебных функций переименования. Node-тест проверяет совпадение с исходной функцией, runtime-тест исполняет копию из готовой HTML-страницы. `node scripts/render-planner-preview.mjs` генерирует docs/planner-preview.html с вымышленными данными. Вторым аргументом можно выбрать empty/busy. Личные данные для этих артефактов не используются.

Источники: [Telegram Mini Apps: запуск и проверка initData](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app), [Bot API: InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton). Механизм не требует оплаты за ИИ, но сервер и Telegram подчиняются своим ограничениям эксплуатации.

Серверная публикация: 34aea726-ef82-4aab-86ea-2fe3b0088685. На опубликованном сервере проверены HTTP 200 оболочки, HTTP 401 без подписи и закрытое чтение с корректной HMAC. Вернулись четыре открытых дела и текущая зона; реальные названия не выводились. Это служебная проверка API, а не вход из клиента Telegram. Сохранённые настройки и ресурс ИИ не сброшены.
