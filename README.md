# BOB — личный помощник в Telegram

[![CI](https://github.com/hugo3301/Assistant_BOB/actions/workflows/ci.yml/badge.svg)](https://github.com/hugo3301/Assistant_BOB/actions/workflows/ci.yml)
[![Deploy](https://github.com/hugo3301/Assistant_BOB/actions/workflows/deploy.yml/badge.svg)](https://github.com/hugo3301/Assistant_BOB/actions/workflows/deploy.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

BOB помогает собирать дела, пары, встречи и дедлайны в один план. Напиши обычным текстом или отправь голосовое, посмотри неделю и получи напоминание перед событием.

**Альфа:** [@mybob_robot](https://t.me/mybob_robot). Регистрация открыта через `/start`; у каждого участника свои данные и настройки.

## Возможности

- Задачи, встречи, сроки и уточнения обычной русской речью; возврат последнего изменения.
- Голосовые сообщения: Cloudflare по умолчанию, Groq по отдельному выбору.
- Утренняя сводка, напоминания перед встречами, повторяющиеся дела.
- Импорт `.ics` с выбором своих групп и защитой от дублей.
- Двусторонние Google Calendar и Яндекс Календарь; живой аккаунтный пилот ещё предстоит.
- Календарь дня и недели внутри Telegram, обзоры дальних сроков и проектов.
- Меню и обычные просмотры без LLM; непрофильные запросы отсекаются до генерации.

| Команда | Что показывает |
| --- | --- |
| `/today` | Сегодня |
| `/week` | Ближайшие семь дней |
| `/ahead` | Дальние сроки и общая картина |
| `/tasks` | Список задач |
| `/find текст` | Поиск |
| `/calendars` | Подключение внешних календарей |
| `/providers` | Провайдеры, согласия и лимиты |
| `/cancel` | Отмена текущего уточнения |

Время сводки, часовой пояс и напоминания хранятся отдельно для каждого пользователя. Обновления их не сбрасывают.

## Как устроен

| Часть | Реализация |
| --- | --- |
| Telegram и фоновые задания | Cloudflare Worker, webhook, Cron и Durable Object alarms |
| Дела и настройки | Изолированные SQLite Durable Objects |
| Общие квоты и доступ | ControlObject, постоянные резервы и учёт расхода |
| Планировщик в Telegram | Mini App с серверной проверкой Telegram initData |
| Текст | Workers AI; GigaChat-3-Ultra только для личного пилота владельца |
| GigaChat transport | Подписанный Node-мост на Netlify Free с отдельным CA |
| Голос | Cloudflare либо добровольно выбранный Groq STT |

Модель предлагает действия, приложение проверяет их перед записью. Удаления и неоднозначные просьбы имеют отдельные проверки. Квоты не смешивают токены, аудиосекунды и Cloudflare neurons; скрытого платного fallback нет.

## Локальная разработка

Нужны Node.js24+ и npm. Тесты используют вымышленные данные и подменённые внешние API: реальные ключи и платные запросы не нужны.

```sh
git clone https://github.com/hugo3301/Assistant_BOB.git
cd Assistant_BOB
npm ci
npm run ci
npm run demo
npm run chat
```

`chat` — отдельный локальный CLI, он не запускает второго Telegram polling-процесса. Без AI-ключа доступны локальные команды и правила. Локальные базы и результаты сборки появляются в исключённом `work/`.

Для своего подключения скопируй [.env.example](.env.example) в `.env` и настрой собственные аккаунты. Пример содержит только пустые поля и выключенные дополнительные провайдеры. При собственном развёртывании также замени account/name в `wrangler.jsonc`; не используй production-ключи чужого бота.

## Проверки и публикация

```sh
npm run check:repo    # Гигиена отслеживаемых файлов и поиск явных ключей
npm test             # Диалог, даты, изоляция, голос, календари, квоты
npm run test:cloud   # Сборка и проверки настоящего workerd/SQLite со stub API
```

CI запускается для push/PR. CD публикует точный commit из успешного CI в `main` и проверяет публичный health; ручной запуск также требует успешного CI этого commit. Секреты работающего Worker сохраняются, Netlify на каждый push не перепубликуется. Устройство, доступ и порядок восстановления: [docs/ci-cd.md](docs/ci-cd.md).

Живые API-проверки вынесены в отдельные scripts и не входят в CI. Их запуск требует отдельного бюджета и разрешения. Текущий лимит двух проб Netlify/GigaChat уже использован.

## Ограничения альфы

- Временные диапазоны вроде «с15:30до16:00» ещё в очереди исправлений.
- Реальный повторный тест голосовых с Android и подключений календарей остаётся отдельным пилотом.
- GigaChat пока доступен только владельцу по согласию в `/providers`: условия личного Freemium для общей публичной альфы не подтверждены.
- GigaChat-пакет — постоянный ресурс до срока провайдера, а не ежемесячное пополнение. Число пользователей не обещает неограниченный бесплатный AI.
- Бесплатные сервисы имеют лимиты и могут приостанавливать работу. Карта, платные планы и автопополнение не подключены.
- GitHub хранит исходники; базы Beads и реальные пользовательские данные не входят в обычный Git push. Проверенное аварийное восстановление ещё в работе.
